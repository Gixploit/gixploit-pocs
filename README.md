---

### Créditos y Reconocimiento

Este repositorio incluye tanto código propio como análisis, adaptaciones y explicaciones de investigaciones realizadas por la comunidad:

- **Atribución original:** Siempre se incluye una referencia explícita al creador o investigador original (nombre o usuario y enlace) en el encabezado del script o en la documentación de la PoC.
- **Respeto de licencias:** Si el código de terceros incluye su propia licencia, esta se mantiene en su directorio correspondiente.
